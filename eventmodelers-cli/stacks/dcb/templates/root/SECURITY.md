# Security

This project's security policies, and the evidence that each one holds, are in [security/](security/README.md):

- [security/POLICY.md](security/POLICY.md): each policy in plain terms, its setting, and where it was decided;
- [security/EVIDENCE.md](security/EVIDENCE.md): the tests that prove each policy, and their last run;
- [security/results/](security/results/): the recorded runs.

Who may call each endpoint is in [api/permissions.md](api/permissions.md), written from the model at export, with the
role map in [api/roles.json](api/roles.json).

To report a vulnerability, contact the project's owners privately rather than opening a public issue.
